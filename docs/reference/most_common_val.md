# Most common value

Internal function for
[get_properties](https://urbaninstitute.github.io/datagoodr/reference/get_properties.md)
to find most common value.

## Usage

``` r
most_common_val(x)
```

## Arguments

- x:

  vector

## Value

most common value in \`x\`

## Details

internal function for
[get_properties](https://urbaninstitute.github.io/datagoodr/reference/get_properties.md)
