# Demo dataset for the datagoodr vignettes

A small synthetic dataset with one column per data type, so each
vignette can build a real DGF and render a real profile for every
reporting style. Values are deliberately in their messy "as-entered"
form (dates as \`M/D/YYYY\`, a boolean as \`yes\`/\`no\`, a zero-padded
FIPS code) so the typing and stabilization steps have something to do.

## Usage

``` r
dg_demo
```

## Format

A data frame with 60 rows and 6 variables:

- event_date:

  character; a calendar date written \`M/D/YYYY\` (temporal).

- region:

  character; one of four regions (categorical).

- is_active:

  character; \`"yes"\`/\`"no"\`, recoded to logical (boolean).

- revenue:

  numeric; a right-skewed dollar amount (number).

- county_fips:

  character; a zero-padded 5-digit county FIPS (identifier).

- notes:

  character; short free-text notes (text).
